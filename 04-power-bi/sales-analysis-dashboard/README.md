# Sales Analysis Dashboard | Power BI

## Project Overview

This project explores sales performance using Power BI. It demonstrates data preparation, DAX calculations, interactive visualizations, and basic validation of sales figures.

## Objectives

- Explore sales performance across regions.
- Compare revenue across product categories and products.
- Enable interactive exploration using region and date filters.
- Validate calculated sales totals against the existing sales data.

## Tools Used

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Excel

## Data Preparation

- Imported sales data from Excel.
- Inspected column data types and data quality.
- Checked for blank rows and missing values.
- Loaded the prepared data into Power BI.

## Analysis and Visualizations

The dashboard includes:

- **Total Sales:** A KPI card showing overall sales.
- **Total Sales by Region:** A comparison of sales across regions.
- **Sales by Product Category:** A breakdown of sales by category.
- **Sales by Product:** A comparison of revenue generated by individual products.
- **Interactive filters:** Region and date slicers.

## Validation

The calculated total sales measure was compared with the existing `TOTAL SALES` column. Both displayed approximately 619K.
